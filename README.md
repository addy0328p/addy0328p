TripAI is a **multi-agent travel planning platform** that coordinates specialized AI agents to generate personalized travel plans.

- 🧠 Supervisor-based routing across **flight, hotel, weather, budget and itinerary agents**
- 🔗 Built using **LangGraph, LangChain and MCP**
- 🌐 Integrated **Tavily, AviationStack and OpenWeather** for real-time travel information
- 🙋 Supports **Human-in-the-Loop approval**
- 💾 PostgreSQL-backed workflow persistence
- 🛡️ Input validation and guardrails
- 🐳 Containerized using Docker
- 🚀 Deployed with a live interactive interface
